🏪 WarungAI

Offline-first AI assistant for Indonesian micro-shops (UMKM) — private by default, smart when it counts.

Built with Firebase AI Logic hybrid inference: Gemini Nano on-device in Chrome, Gemini in the cloud as fallback.

System status

  • Cloud model gemini-3.5-flash-lite via Firebase AI Logic

On-device inference needs Chrome desktop 139+ with the Prompt API. If it is not available here, hybrid features automatically use the cloud — and the private feature below refuses to run at all.

1 · Private Sales Notes

On-device only

Paste today's messy sales notes and get a clean, structured summary. Your takings are the most sensitive data your shop has, so this feature runs 100% on your device — it never sends your numbers to the cloud, and it will refuse to run if the on-device model is unavailable.

2 · Customer Reply & Product Copy

Hybrid · prefers on-device

Draft a warm WhatsApp reply and a ready-to-use product description. This feature tries the fast, free on-device model first and falls back to the cloud automatically — the badge on the result shows which one actually answered.

3 · Promo Ideas & Translation

Cloud-first

Creative work deserves the bigger model. Promo ideas, bilingual captions (Indonesian ↔ English) and a WhatsApp broadcast draft — generated cloud-first, with the on-device model as an offline safety net.
